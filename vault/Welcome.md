# Your Project Memory

Keep useful context between tasks. Store short, linked Markdown notes on this computer.

## Start

1. Activate memory for a project with the setup command in the human guide.
2. Record its purpose and current goal in the project home.
3. Keep its manifest short. Link to details when needed.

## Keep Control

Read and edit notes with Obsidian or any text editor. No account, database,
server or community plugin is required by Context Vault. Use your normal
backup tool for this folder. The coding agent service has its own data policy.
